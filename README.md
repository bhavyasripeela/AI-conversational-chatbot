# LLM Conversational Chatbot

A Python-based conversational chatbot built using the Google GenAI SDK.

## Features

- Multi-turn conversation history
- JSON-based persistent conversation storage
- Loads previous conversation history when the application starts
- Secure API-key configuration using environment variables
- Interactive command-line interface

## Tech Stack

- Python
- Google GenAI SDK
- JSON
- python-dotenv
